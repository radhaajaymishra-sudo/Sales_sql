# Sales_sql
Sales project 

## Objective
Analyze sales data using SQL to identify trends and business insights.

## Tools Used
- SQL (MySQL)

## Key Analysis
- Total Sales
- Sales by City
- Top Customers
- Best Selling Products
- Monthly Trends

## Insights
- Delhi contributes the highest revenue
- Electronics category dominates sales
- Top customers drive majority of revenue
- Sales show an increasing trend over months

## Project Structure
- dataset/ → database creation
- queries/ → analysis queries
